Why This Matters

This proof of concept creates repeatable computer vision runs. Each run stores the active detection profile, model, confidence threshold, frame sampling rate, processing workload, and detection results.

The run history makes it easy to compare how different settings affect speed and detection coverage. For example, processing every frame detects more unique persons, while processing every 40th frame is faster but misses more objects.

The current driving profile can detect people, vehicles, bicycles, traffic lights, and stop signs. The same architecture supports future profiles such as airport monitoring, drone detection with a specialized model, and secure facility observation.
