Why This Matters

This proof of concept creates repeatable computer vision runs. Each run stores the active detection profile, model, confidence threshold, frame sampling rate, processing workload, unique-person counts, and warning events.

The warning count proves that the interpretation layer is event-driven. It does not generate a warning for every raw person detection. It generates warnings only when a new unique person is identified.
