Why This Matters

This proof of concept creates repeatable computer vision runs. Each run stores the active detection profile, model, confidence threshold, frame sampling rate, selected object classes, processing workload, unique-person counts, and warning events.

The Video Stream page watches for a new completed run file while the stream is active. When the backend saves the run JSON, the summary is generated automatically.

Planned Drill-Down

Batch Processing now acts as the review console for processed MP4 runs. The next logical improvement is a persistent database-backed run history.
